M1: add trace call values

Accept an optional `--value WORD` on the public trace command, after
the required source and `--calldata`. Options may follow the source
in any order. Duplicate, missing and unknown options, a dash-led
source and a dash-led option value are refused with exit 64 and the
usage row.

Reuse the source model's bounded Word grammar to validate value
before compilation, normalize hexadecimal case, and canonicalize the
logged decimal argument by stripping leading zeroes, since geth's
`--value` flag already parses a leading-zero decimal string as plain
decimal. Forward the normalized value to geth alongside the existing
prestate and code. The default value stays zero.

Add the TRACE-VALUE gate after DIFF-VALUE, with the marker
`TRACE-VALUE live=36 funding=2 refused=34 OK`. It checks 36 source
model and EVM comparisons, the recorded executor arguments of 36
live requests, two funding faults and 34 refusals.

Validation is scoped to this driver change; the complete ladder was
not rerun. DENOMINATORS and M0-RATIO remain under the existing
timing pause, with no milestone exit claim.
